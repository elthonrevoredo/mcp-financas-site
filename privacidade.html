Política de Privacidade — MCP Finanças

Última atualização: 18 de novembro de 2026.

O MCP Finanças é um aplicativo de uso pessoal. Seu único usuário é o proprietário, que o utiliza com a própria conta Google.

Dados acessados

  • Gmail (somente leitura): e-mails de faturas de cartão e de pedidos de compras, para identificar lançamentos.
  • Google Drive: apenas os arquivos criados pelo próprio aplicativo (transcrições das faturas).
  • Google Sheets: a planilha pessoal de controle financeiro do proprietário, para leitura e atualização dos lançamentos.

Uso e compartilhamento

Os dados são usados exclusivamente para a gestão financeira pessoal do proprietário. Não são vendidos, compartilhados com terceiros nem usados para publicidade. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Armazenamento

As credenciais de acesso ficam guardadas como segredos e nunca são publicadas. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
